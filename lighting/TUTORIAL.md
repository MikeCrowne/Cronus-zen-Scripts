# LumenFlow Studio Quick Start

Welcome to **LumenFlow Studio** — a lighting desk concept turned into a working app.

## What makes it different
- **Beginner mode by design:** clear words, fewer hidden pages, fast patching.
- **Advanced power when needed:** cues, palettes, effects, timeline, pixel mapping.
- **One workflow instead of five:** busking, theatre cues, LED looks, and programming tools live together.

## 5-minute tutorial
1. Click **Load Demo Show** to load a ready-made stage.
2. In **Fixture Control**, pick a fixture and adjust intensity, pan, tilt, beam, and color.
3. Use **Groups & Palettes** to quickly wash the rig or apply a shared color/position idea.
4. Press **Record Cue** to store the current stage look.
5. Trigger cues from the **Cues** panel.
6. Start the built-in timeline from **Transport** for theatre/automation playback.
7. Open **Pixel Mapping** and switch between Wave, Rainbow, and Sparkle looks.
8. Toggle **Effects** like Pulse, Color Chase, and Orbit for movement and energy.

## Suggested workflow
### Concert / busking
- Use palettes for color families.
- Run intensity groups with a fader-like workflow.
- Toggle effects during drops and solos.

### Theatre / corporate
- Build static cues with notes.
- Add timeline events for deterministic playback.
- Save often and keep clean naming.

### LED / scenic work
- Use pixel mapping looks for quick previs.
- Extend the matrix later to real sACN/Art-Net nodes.

## Feature map
- **Real-time control:** fixture sliders, quick palette apply, group intensity.
- **Visualization:** stage data cards and live pixel preview.
- **Pixel mapping:** integrated effect engine for LED walls and scenic strips.
- **Automation:** cue storage plus timeline run/stop transport.
- **Versatility:** works without hardware, but models a production-ready desk layout.

## Future expansion ideas
